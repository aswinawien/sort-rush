# Design System

## Direction: glitchy counterculture

Sort Rush should feel like a strange independent zine that learned to run a very precise arcade machine. Irregularity is allowed around the play field; active gameplay remains calm, high-contrast, and legible.

## Novelty budget

- Active game: 20% experimentation, 80% clarity.
- Tutorial: expressive but obvious.
- Home and results: 60% experimentation.
- Settings: conventional and quiet.

## Visual rules

- Use a warm off-white or near-black base with one acidic accent and one warning color.
- Use oversized display typography for score and compact mono labels for system-like copy.
- Use misregistration, scan lines, offset borders, and imperfect stickers sparingly.
- Keep bins large, separated, and distinguishable by shape plus color.
- Never communicate package identity by color alone.

## Interaction rules

- Portrait, one-thumb play.
- Destination controls must be large and forgiving.
- Feedback must appear at the point of action and in the score/combo region.
- Unusual transitions are acceptable; unusual core controls are not.
- Every error state must explain what happened without blaming the player.

## Accessibility

- Pair colors with symbols or package silhouettes.
- Maintain readable contrast.
- Support sound-off play.
- Avoid rapid flashing.
- Respect system text scaling outside the game canvas.

## Required design-brief fields

Purpose, player question, primary action, secondary actions, hierarchy, exact copy, states, touch targets, motion, sound/haptic behavior, accessibility, responsive behavior, Flutter/Flame mapping, and acceptance criteria.

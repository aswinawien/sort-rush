# Anti-Mainstream UI/UX

Act as the UX Critic. Read `CLAUDE.md`, `docs/product-brief.md`, and `docs/design-system.md`. Design a glitchy counterculture interface without sacrificing active-game clarity.

For every important screen provide a bold version and safer fallback, exact copy, hierarchy, touch targets, states, motion, sound/haptics, accessibility, responsive behavior, Flutter/Flame mapping, and acceptance criteria. Score alternatives for comprehension, touch safety, distinctiveness, implementation cost, and failure risk. Choose based on clarity. Do not create a style-only moodboard or silently change gameplay rules.

# Claude Design Handoff

Turn the approved UX into implementation-ready design briefs. Read the product, design, level, and decision documents. For each screen and interaction specify purpose, player question, primary/secondary actions, layout, exact copy, states, touch targets, motion timing, audio/haptic events, accessibility, responsive rules, Flutter widgets, Flame components, and acceptance tests.

Return a screen/state map, component inventory, token table, two alternatives for high-impact screens, selected direction, and unresolved decisions. Do not invent assets or APIs that are not needed for the current milestone.

# Level Design

Act as the Level Designer. Read `docs/level-spec.md`, product brief, and approved design. Build 8–12 curated levels that each teach one pressure, then define the endless curve from measured curated parameters.

For every level provide duration, spawn interval, speed, package kinds, active-package limit, mistake limit, pass condition, intended feeling, likely failure point, tutorial copy, and acceptance test. Avoid random spikes and never add a mechanic without a teaching purpose. End with a balancing worksheet and a human approval packet.

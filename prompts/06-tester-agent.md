# Tester Agent

Act as the Test Agent. Read `CLAUDE.md` and `docs/testing-strategy.md`. Inspect the current implementation and run static analysis, unit/component/UI tests, and deterministic scripted scenarios.

Cover launch, tutorial, correct/wrong sorting, combo, timeout, pause/resume, restart, backgrounding, persistence, sound-off, screen sizes, text scaling, orientation, rapid taps, boundaries, fixed seed, and malformed save data. Report reproducible bugs with ID, severity, evidence, build, device, seed/level, suspected subsystem, smallest fix, and regression test. Scripted tests do not replace human playtesting.
